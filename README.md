# Dennis Portfolio

Personal portfolio website created for CSCI 39548: Practical Web Development.

## Overview

This project is a simple personal portfolio website built using HTML and CSS. The website includes:

- About Me section
- Professional Experience section
- Technical Skills section
- Contact section
- Personal profile photo

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub

## GitHub Workflow

This project was developed using a GitHub workflow that included:

1. Creating a GitHub repository
2. Creating a feature branch (`feature/portfolio-page`)
3. Making commits while developing the website
4. Pushing changes to GitHub
5. Creating a Pull Request
6. Merging the Pull Request into `main`
